## Mission

Lum0s Solutions is an AI-native offensive-security studio. We design **sovereign operating systems**, **governed multi-agent toolchains**, and **constitutional AI frameworks** for teams who need to move fast without giving up auditability.

We don't ship features &mdash; we ship **doctrine**. Every line of code, every agent, every protocol is shaped by one question: *can this be trusted to defend something that matters?*

## What We Build

| Product | Description | Stage |
|---|---|---|
| **Syn_OS** | Sovereign AI-assisted cognitive hyper-OS on Arch Linux. Custom Rust kernel interface, integrated offensive-security toolchain, gamified training, constitutional governance. | `v111 · code-complete` |
| **GRIMOIRE** | Gamified cybersecurity training that runs real tools in sandboxed labs &mdash; the game is the wrapper, the practice is real. | `1.0 · public edition` |

## Operating Doctrine

> **Sovereignty over convenience.** The human is always the final authority. No agent commits, ships, or speaks for the org without governed consent.

> **Constitutional governance.** Agents operate under written charters. Behavior is auditable, not emergent-by-accident.

> **Defense in depth, doctrine in depth.** Layers across data, agents, code, and runtime &mdash; backed by written threat models.

> **Build in public where it strengthens defenders.** Sensitive offensive tooling is held under disciplined release.

> **Shadow integration.** We red-team our own systems. The unconscious of a codebase is where the breaches live.

## Get Started

```bash
# clone the community edition
git clone https://github.com/Lum0s-Solutions/CoM-Syn_OS-Public.git
cd CoM-Syn_OS-Public

# build the community ISO
just iso churchofmalware
```

The base OS and GRIMOIRE training build **key-free**; the full offensive image needs a Church key. Not building from source? A published ISO ships from the [website](https://synos-linux.pro). See the [download &amp; build guide](https://synos-linux.pro/guides/download/) for the full open-core split.
